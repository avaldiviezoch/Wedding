# Skill: design

Úsala para cambios visuales, animaciones, componentes y microinteracciones.

## Principios

- La simplificación de código no debe convertir la interfaz en genérica.
- Mantener jerarquía visual, espaciado, proporción, tipografía y consistencia entre módulos.
- Reutilizar componentes y patrones existentes antes de crear variantes nuevas.
- Las animaciones deben aportar contexto y fluidez, no bloquear interacción.
- Evitar saltos de layout, flashes de interfaces anteriores y cargas visuales superpuestas.
- Respetar estados hover, focus, active, disabled, loading, empty y error cuando correspondan.
- Mantener accesibilidad básica: contraste suficiente, foco visible, etiquetas y controles utilizables.

## Antes de entregar

Revisar desktop y móvil, transiciones de entrada/salida, scroll, modales y consistencia con el resto del producto. Si una nueva propuesta requiere duplicar una implementación completa, justificarlo antes de hacerlo.
