# Skill: design

Esta skill se mantiene por compatibilidad. Para cambios visuales nuevos usar `../visual-system/SKILL.md`.

## Regla

Aplicar el sistema visual de Mi Gran Día y asumir modo NORMAL salvo que el usuario pida explícitamente REFINE o REDESIGN.

No crear una estética paralela, no montar un rediseño encima de la interfaz anterior y no simplificar hasta volver genérica la experiencia.
