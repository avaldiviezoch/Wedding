# Wedding Visual Polish

Act only after `wedding-ui-review` and the project design system establish the constraints.

- Preserve the screen's purpose, structure, navigation, responsive behavior and component vocabulary.
- Prefer fewer, stronger visual decisions over added decoration.
- Improve hierarchy through scale, weight, spacing, alignment and contrast before adding effects.
- Keep one coherent focal point and reduce competing emphasis.
- Reuse current tokens and assets. Do not invent a generic aesthetic or copy an external brand.
- Treat motion as feedback or spatial explanation, not decoration.
- Validate mobile and desktop; polish that harms readability, accessibility or performance is a regression.
- Present optional taste judgments separately from objective defects.
