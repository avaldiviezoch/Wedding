# Invitación 6 — Base definitiva

Esta carpeta contiene la nueva base independiente para la invitación definitiva de Antonio y Lucero.

## Estructura

- `index.html`: estructura principal de la invitación.
- `styles.css`: estilos base y diseño responsive.
- `app.js`: lógica inicial, actualmente cuenta regresiva.
- `assets/`: carpeta reservada para imágenes, videos, audio, fuentes y demás recursos propios de esta versión.

## Regla de trabajo

Esta versión debe evolucionar de forma aislada. No modificar ni reutilizar archivos internos de `invitacion_1` a `invitacion_5` mediante rutas relativas que generen dependencias entre versiones.

Las integraciones de RSVP, música, mapas u otros servicios se incorporarán de manera explícita cuando sean definidas y validadas.
